# Studiu individual PAD

## Proiect Java

Acest proiect a fost realizat pentru exersarea utilizării sistemului Git.

Programul Main.java calculează suma acumulată prin depuneri lunare.

### Datele programului:
- Depunere lunară: 500 lei
- Dobândă anuală: 7%
- Perioada: 20 de ani

### Tehnologii utilizate:
- Java
- Git
- Git Bash
